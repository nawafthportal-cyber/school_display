# الثيمات الخاصة لشاشات المدرسة

من **شاشات العرض ← الثيمات الخاصة** يمكن إنشاء ثيم خاص، تعديله ونسخه أو حذفه.
يمكن أيضًا اختيار الثيم المحفوظ من قسم الهوية البصرية في تخصيص جميع الشاشات
أو تخصيص شاشة واحدة. الثيمات مملوكة للمدرسة، وتظل متاحة لمسؤوليها المصرح لهم.

## التخصيص والتطبيق

- الألوان: الخلفية والبطاقات والنصوص والعناوين واللون الرئيسي.
- الخلفية: لون موحد أو تدرج هادئ أو نقاط خفيفة.
- الخط: IBM Plex Sans Arabic المحلي، أو خط الجهاز، أو Arial.
- حجم النصوص: 90–115%، واستدارة البطاقات: 0–32 بكسل.
- المعاينة تستخدم محرك الألوان نفسه المستخدم في التلفاز، ببيانات توضيحية.
- يتحقق الخادم والمتصفح من التباين: 4.5:1 للنصوص و3:1 للعناوين واللون الرئيسي
  على كل من الخلفية والبطاقات. لا يقبل المحرر CSS أو روابط صور أو خطوط خارجية.

خيارات التطبيق:

1. **الإعداد العام**: تتبعه الشاشات الوارثة، وتبقى الشاشات المخصصة مستقلة.
2. **جميع الشاشات**: يغيّر الإعداد العام ويمحو تجاوزات الثيم للشاشات التابعة
   للمدرسة فقط؛ تبقى إعدادات المحتوى والشعار والسرعة الخاصة بكل شاشة كما هي.
3. **شاشة محددة**: تُحفظ هوية مستقلة لتلك الشاشة.

اختيار لون جاهز من لوحة الألوان يلغي اختيار الثيم الخاص لذلك الإعداد.
حذف ثيم يعيد مستخدميه إلى ألوان الثيم الجاهز الذي بدأ منه. تعديل ثيم مستخدم
يرفع مراجعة العرض ويرسل تحديثًا للشاشات بعد نجاح الحفظ. تحتفظ المناسبات
والتنبيهات الطارئة بألوانها الدلالية. تُخزّن ملفات محرك الثيم في Service Worker
لتعمل الهوية المحفوظة عند انقطاع الاتصال أيضًا.

## الترحيلات والتحقق

تضيف `schedule.0025` جدول الثيمات وربطًا اختياريًا بإعداد المدرسة، وتضيف
`core.0038` ربطًا اختياريًا للشاشة. لا يُختار ثيم خاص لأي مدرسة تلقائيًا.
يجب تطبيق الترحيلين قبل تشغيل إصدار التطبيق الذي يستخدم الحقول الجديدة.

```sh
python manage.py migrate --noinput
python manage.py test dashboard.test_custom_themes dashboard.test_custom_themes_browser core.test_csp
npm run build:display
```

اختبارات المتصفح تتحقق من المعاينة والحفظ والتطبيق الفعلي، ومن عرض الجوال
دون تجاوز أفقي أو مخالفات CSP. المحرر يغير الهوية البصرية؛ توزيع عناصر شاشة
العرض ومحتواها يبقيان تحت إعدادات النظام الحالية.
